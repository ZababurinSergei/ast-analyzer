# ПРАВИЛА ЧАТА (минимальные)

## 1. Формат заданий
Каждое сообщение заканчивается ОДНИМ блоком ```bash```:
- не чистит консоль;
- **не очищает и не перезаписывает логи** — только append `>>` в `./tmp/<task>-<TS>/run.log`;
- **никакого `exec` для перенаправления всего вывода.** Логирование — через явную функцию-обёртку (`log()` / `run()`), либо `tee -a` в каждой команде, либо запись напрямую в файл + отдельный `tail -f`. Пайпы и stdout/stderr остаются видимыми интерактивно;
- не перезаписывает исходники без `.bak-<TS>`;
- собирает контекст для следующего шага;
- печатает список артефактов и что прислать;
- включает всё нужное: save / read / grep / jq / diff / round-trip / patch.
- Внутри блока `bash` первым делом:
  `TS=$(date +%Y%m%d-%H%M%S); TASK="<task>"; DIR="./tmp/${TASK}-${TS}"; mkdir -p "$DIR"; LOG="$DIR/run.log"; : >> "$LOG"`.

## 3. Playwright — правила запуска
1. **HTTP-сервер, не `file://`.** Chromium блокирует `fetch` к `file://`. Всегда поднимай HTTP-сервер в директории viewer'а.
2. **Убивай старые серверы.** `pkill -9 -f "http-server"; pkill -9 -f "http.server"` перед стартом.
3. **Случайный порт.** `PORT=$((40000 + RANDOM % 20000))` + проверка занятости через `/dev/tcp`.
4. **Проверяй «наш ли файл».** `curl URL/index.html | grep -q "<title>Граф-инспектор"` — иначе `exit 1`. Плюс `curl URL/index.json` → 200.
5. **`console.log` — в `finally`.** Playwright падает на `click` по disabled-кнопке. Лог пишется до `browser.close()`. Обязательно `page.on('console'/'pageerror'/'requestfailed')`.
6. **`waitForFunction(__astDebug)`** с таймаутом ≥ 60 сек.

## 4. Логи
Логи не удаляются, не трутся, не ротируются. Только `>>` (append). Никаких `>` и `rm`.
