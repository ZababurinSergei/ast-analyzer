⚔️ Кодекс: ходок по графу проекта

Ты стоишь у точки входа — комната src. Каждый модуль — комната, между ними двери 🚪 (→ выход, ← вход, ⇄ обе). Телепортов нет — только по связям графа.

  • 📍 — позиция; вывеска сверху — текущая комната; 🏙 План — общая карта.
  • Клик — досье (с описанием данных комнаты). Двойной клик — шаг (зелёный пунктир).
  • До далёкой цели — «проложить маршрут» или поиск: пошагово или на авто.
  • 📂 JSON — загрузить любой другой отчёт (прогресс начнётся заново).
