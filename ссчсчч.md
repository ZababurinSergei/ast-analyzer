# 🎯 План: React-сущности в дереве (Вариант B — Tree)

## Принятая архитектура

**Вариант B — Tree:** React-сущности рендерятся **иерархически**, где **компонент** — корень, **хуки/эффекты/jsx/события** — его дети.

## 📐 Целевая структура дерева

```
📄 App.tsx (hasChildren: true)
  ├── ⚛️ App                                     [component]  depth=0
  │     ├── 🪝 useState (count)                  [hook]       depth=1
  │     ├── 🪝 useState (data)                   [hook]       depth=1
  │     ├── ⚡ useEffect (mount)                  [effect]     depth=1
  │     ├── 🔗 useRef (inputRef)                 [ref]        depth=1
  │     ├── 🌳 <div>                             [jsx]        depth=1
  │     │     └── 🖱 onClick → handleClick        [jsx-event]  depth=2
  │     └── 🌳 <ChildComponent>                  [jsx]        depth=1
  │           └── 🎨 <ChildComponent>            [usage]      depth=2
  ├── ⚛️ ChildComponent                          [component]  depth=0
  │     └── 🪝 useState (value)                  [hook]       depth=1
  ├── 🔗 ThemeContext                            [context]    depth=0
  ├── 💾 memo(Item)                              [memo]       depth=0
  └── ❓ isLoading && <Spinner/>                 [conditional] depth=0
```

## 🎨 Маппинг: React-сущности → иконки/depth

| Сущность | Иконка | Depth | Источник данных | Привязка |
|---|---|---|---|---|
| **Component** | ⚛️ | 0 | `reactComponentsByFile[fileId]` | fileId |
| **Hook** | 🪝 | 1 | `hooksByComponent[compId]` | componentId |
| **Effect** | ⚡ | 1 | `effectsByComponent[compId]` | componentId |
| **Ref** | 🔗 | 1 | `refsByFile[fileId]` | fileId |
| **JSX Element** | 🌳 | 1 | `jsxByComponent[compId]` | componentId |
| **JSX Event** | 🖱 | 2 | `jsxEventsByComponent[compId]` | componentId |
| **Context** | 🔗 | 0 | `contextsByFile[fileId]` | fileId |
| **Memoization** | 💾 | 0 | `memoizationByFile[fileId]` | fileId |
| **Conditional** | ❓ | 0 | `conditionalsByFile[fileId]` | fileId |
| **Component Usage** | 🎨 | 1 | `jsxElementsByFile[fileId]` где `kind === 'component'` | fileId |

### 🎯 **WS-28: Реализовать `renderReactEntities(fileId, ctx)`**

**Цель:** написать функцию рендера React-сущностей.

**Алгоритм:**

```javascript
function renderReactEntities(fileId, ctx) {
  if (!fileId) return '';
  const state = /* ... */;
  const parts = [];

  // ════════════════════════════════════════════════════════════════════════
  // 1. Компоненты файла (корневые узлы, depth=0)
  // ════════════════════════════════════════════════════════════════════════
  const components = state.reactComponentsByFile?.[fileId] || [];
  for (const c of components) {
    // Рендер компонента
    parts.push(renderReactComponentRow(c, 0));

    // ════════════════════════════════════════════════════════════════════
    // 1a. Хуки компонента (depth=1)
    // ════════════════════════════════════════════════════════════════════
    const hooks = state.hooksByComponent?.[c.id] || [];
    for (const h of hooks) {
      parts.push(renderReactHookRow(h, 1));
    }

    // ════════════════════════════════════════════════════════════════════
    // 1b. Эффекты компонента (depth=1)
    // ════════════════════════════════════════════════════════════════════
    const effects = state.effectsByComponent?.[c.id] || [];
    for (const e of effects) {
      parts.push(renderReactEffectRow(e, 1));
    }

    // ════════════════════════════════════════════════════════════════════
    // 1c. JSX-элементы компонента (depth=1)
    // ════════════════════════════════════════════════════════════════════
    const jsx = state.jsxByComponent?.[c.id] || [];
    for (const j of jsx) {
      parts.push(renderReactJsxRow(j, 1));

      // ── JSX-события этого элемента (depth=2) ──
      const events = state.jsxEventsByComponent?.[c.id] || [];
      const elEvents = events.filter(e => e.elementId === j.id);
      for (const ev of elEvents) {
        parts.push(renderReactJsxEventRow(ev, 2));
      }
    }
  }

  // ════════════════════════════════════════════════════════════════════════
  // 2. Контексты файла (depth=0)
  // ════════════════════════════════════════════════════════════════════════
  const contexts = state.contextsByFile?.[fileId] || [];
  for (const ctx of contexts) {
    parts.push(renderReactContextRow(ctx, 0));
  }

  // ════════════════════════════════════════════════════════════════════════
  // 3. Memoization (depth=0)
  // ════════════════════════════════════════════════════════════════════════
  const memo = state.memoizationByFile?.[fileId] || [];
  for (const m of memo) {
    parts.push(renderReactMemoRow(m, 0));
  }

  // ════════════════════════════════════════════════════════════════════════
  // 4. Conditionals (depth=0)
  // ════════════════════════════════════════════════════════════════════════
  const conds = state.conditionalsByFile?.[fileId] || [];
  for (const cd of conds) {
    parts.push(renderReactConditionalRow(cd, 0));
  }

  // ════════════════════════════════════════════════════════════════════════
  // 5. Refs файла (depth=0, если не привязаны к компоненту)
  // ════════════════════════════════════════════════════════════════════════
  const refs = state.refsByFile?.[fileId] || [];
  // (только те, у которых нет componentId, или они уже показаны через компонент)
  // ...

  return parts.join('');
}
```

// ⚛️ Компонент
function renderReactComponentRow(c, depth) {
  const indent = depth * 20;
  const kindLabel = reactComponentKindLabel(c.kind); // 'ƒ function', '💾 memo', ...
  const title = `⚛️ ${c.name} (${c.kind}) — L${c.line}`;
  const isMemoized = c.isMemoized ? ' 💾' : '';
  const isForwardRef = c.isForwardRef ? ' 🔗' : '';
  
  return `
    <div class="fs-fn fs-fn-react-component" data-react-kind="component"
         data-react-id="${escapeHtml(c.id)}"
         data-fs-file-id="${escapeHtml(c.fileId)}"
         data-fs-action="select-file"
         data-fs-id="${escapeHtml(c.fileId)}"
         style="padding-left:${6 + indent}px"

         data-fs-id="${escapeHtml(cd.fileId)}"
